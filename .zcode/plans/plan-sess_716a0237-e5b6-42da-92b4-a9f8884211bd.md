# Production-Grade UI/UX Refinement Plan — Catch Beauty

**Approach: refinement, not redesign.** We keep the existing layout, pages, velvet-crimson identity, IBM Plex Sans Arabic, and all component structure. We fix the systemic gaps found in the audit: missing tokens/primitives, token bypass, typography drift, i18n/trust leaks, touch-target and accessibility issues, and missing route states.

---

## Phase 1 — Foundation (design tokens + global consistency)

**Files:** `src/app/globals.css`, `src/shared/utils/cn.ts`

1. **Extend `@theme` with production tokens** (no visual redesign — codify what exists and normalize outliers):
   - **Radius scale tokens**: `--radius-xs…2xl` mapped to a coherent scale; consolidate the 8+ radius values in use down to 4 tiers (sm=rounded-md for chips/inputs, md=rounded-lg for buttons, lg=rounded-xl for cards — the dominant card radius, xl=rounded-2xl for modals/hero).
   - **Shadow scale**: keep the existing `card-shadow`/`header-shadow` utilities as the canonical elevations; add `elev-1/2/3` tokens; retire ad-hoc `shadow-[…]` and mixed `shadow-primary/40` usages in favor of these.
   - **Semantic colors**: add `--color-warning` (missing), `--color-error` (replace scattered `red-500` usage with a token), `--color-text-muted`; normalize `--color-border-light` (`#E0E7EF` is a cold blue outlier among warm neutrals → warm equivalent).
   - **Typography scale**: define `--text-*` size/line-height pairs and add consistent heading classes; replace scattered arbitrary font sizes (`text-[10px]`, `text-[15px]`, `text-[16px] sm:text-[17px] lg:text-[18px]`) with the scale.
   - **z-index scale tokens**: `dropdown/modal/toast` replacing `z-[100]`, `z-[200]`, stray `z-[1]`.
2. **Fix `cn()`**: add `clsx` + `tailwind-merge` so conflicting classes resolve (prerequisite for the Button primitive).
3. **Global base polish**: consistent `:focus-visible` ring style (primary-tinted, 2px) for keyboard users; `::selection`; smooth-but-restrained default transition tokens (150ms/200ms).

## Phase 2 — Core primitives (`src/components/ui/`)

Build the missing primitive layer per AGENTS.md rules (presentational only), then **migrate usages** — no visual redesign, the primitives absorb the existing dominant styles:

4. **`Button.tsx`**: variants `primary | secondary | outline | ghost | danger`, sizes `sm | md | lg`, with consistent heights (36/44/48px — 44px+ satisfies touch targets), loading spinner state, disabled state, optional leading icon. Migrate the ~60 hand-rolled `bg-primary` buttons (RetryButton, CartSection CTA, ProductActions add-to-cart, banner CTAs) to it.
5. **`Input.tsx` + `Textarea`**: shared field wrapper with label, error text, focus ring, RTL-safe — used by checkout, contact, coupon, auth forms.
6. **`Badge.tsx`**: consolidate discount/flash/new/out-of-stock badges (ProductCard's badge styles become the canonical look).
7. **`Modal.tsx` / `Sheet.tsx`**: shared focus-trapping dialog used by VariantDialog, MobileFiltersModal, MapPickerModal, AuthModal (consistent overlay, radius, close behavior, ESC handling).
8. **`QuantityStepper.tsx`**: one stepper used by ProductCard, ProductActions, and cart — fixes the tiny `h-3 w-3` cart buttons (touch-target P0).
9. **Consolidate `EmptyState`/`ErrorState`** (95% duplicated) into one component with an `error` variant; `RetryButton` becomes a `Button` consumer.
10. **Icons**: keep `lucide-react` as the system; keep `react-icons` only in `SocialIcons` (brand glyphs are a legitimate exception). Verify uniform stroke width/size at call sites.

## Phase 3 — Token-bypass cleanup + i18n/trust fixes

11. **Replace hardcoded colors** with tokens: `bg-[#f4f5f7]` (categories mobile), `from-[#FF6B00] to-[#FF5500]` (FlashSalePromoBanner → brand-aligned), `from-black via-[#1a1a1a] to-[#2a2a2a]` (→ `secondary` ramp), `text-[#111]`, `global-error.tsx` inline hexes, Tailwind-palette usages in ProductCard/FlashSaleCard/OtpInput (`red-500` → error token, `emerald-*` → success token, `gray-*` → text/border tokens, `orange-600` flash badge → discount token).
12. **Currency formatter**: `shared/utils/formatMoney(amount, locale)` with proper Intl formatting for en/ar; replace all `"K.D"` string concatenation (CartSection, CartSummary, ProductCard, FlashSaleCard). **Open question for you below** re: K.D vs EGP mismatch.
13. **i18n leaks**: move CheckoutForm validation messages (lines 58–66) to `messages/{en,ar}.json`; move footer content from `footerService.ts` inline conditionals into message files; translate English-only aria-labels ("Remove item", etc.).
14. **Accessibility fixes**: add `alt` to the ~10 bare `<img>`s; aria-labels on icon-only quantity buttons; check heading order per page (single h1, logical h2/h3); verify contrast of `text-secondary` `#706565` on white (≈4.6:1, passes) and fix any sub-4.5 text tokens.
15. Remove stray `src/features/auth/types.ts.bak`.

## Phase 4 — Core ecommerce UX

16. **Sticky header slimming**: on scroll past the fold, only the compact MainNav row stays sticky (CategoryNav scrolls away) using the existing `useScrollState` hook — huge vertical-space win without changing the header design.
17. **Breadcrumbs** added to search, brands, tags, wishlist pages (component already exists).
18. **Cart polish**: real stock values instead of fabricated `stock_quantity: 999` (surface `in_stock` properly, disable stepper at max, show out-of-stock state); consistent stepper sizing; price/subtotal alignment pass.
19. **Product card polish** (no redesign): normalize discount badge presentation, old/new price relationship (strikethrough weight/color), truncation to 2 lines with consistent line-height, consistent hover elevation via `card-shadow-hover`, loading skeleton consistency.
20. **Route state completion**: add `error.tsx` to `/wishlist`; add `loading.tsx` to `/category/[slug]`, `/search`, `/brands`, `/tags` (skeleton components already exist — wire them).
21. **Checkout trust pass**: consistent Button/Input usage, translated validation, order summary alignment, clear error mapping for payment failed state.

## Phase 5 — Responsive + micro-interaction QA

22. Mobile pass: bottom-nav safe-area padding, modals as bottom sheets on mobile, touch targets ≥44px across cart/filters/qty, no horizontal scroll.
23. Transition consistency: standardize hover/press transitions to the token durations; ensure skeletons match final layout dimensions (no layout shift).

## Phase 6 — Final polish & verification

24. Sweep remaining arbitrary values (`w-[…]`, `h-[…]`) only where they map cleanly to tokens — leave genuinely computed ones.
25. Run `npm run lint` + `npm run build`; visually verify key journeys (home → category → PDP → cart → payment) on desktop + mobile widths, both `en` and `ar` (RTL) locales.

## Out of scope (explicitly)
- No new pages, no redesign of layout/structure, no new animation library, no dark mode, no cart drawer (that's a feature addition, not refinement).
